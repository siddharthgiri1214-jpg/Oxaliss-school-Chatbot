# Oxaliss School Chatbot

## Run
```
pip install --upgrade -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

The Groq API key is read from the `.env` file (`GROQ_API_KEY=...`). Do not share that file.
Languages: English, Tamil, Hindi, Telugu, Kannada, Malayalam (answers, voice input and voice output follow the selected language).
